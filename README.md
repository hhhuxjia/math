# math
# 考研数学知识点专题

本仓库用于整理和记录考研数学相关知识点专题。

仓库中的内容主要依靠 **AI 辅助编写、整理和完善**，用于个人考研数学学习与复习。

## 内容

目前主要包括：

- 高等数学
- 线性代数
- 概率论
- 各类重点、难点与压轴题专题
- 公式与知识点整理

文件主要采用 Markdown（`.md`）格式编写。

## 阅读方式

推荐使用 **Visual Studio Code（VS Code）** 打开 `.md` 文件。

VS Code 自带 Markdown 默认渲染器，可以直接预览排版后的内容：

> `Ctrl + Shift + V`

也可以使用右上角的 **Open Preview** 打开预览。

## 用途

本仓库主要供**个人学习、复习和知识整理使用**。

部分内容由 AI 辅助生成，因此内容可能存在错误或不严谨之处，仅作为学习资料参考。
